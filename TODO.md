# Entregas — Apresenta

## Editor local, sem cadastro, para PC
- [x] Criar interface amigável, simples e prática, sem login e aplicativo de PC (PWA instalável, sem exigir conta).
- [x] Precisa ser rápido, tanto para receber quanto para apresentar e projetar; “colocou apresentou”.
- [x] Aplicar processamento e armazenamento local dos arquivos sempre que possível, sem conta.

## Importação, ordenação e repetição da sequência
- [x] Possível inserir arquivos, links no meio de uma apresentação.
- [x] Possível o usuário organizar a ordem dentro da interface.
- [x] O usuário coloque exatamente onde termina e começa o próximo arquivo, seja ele PPTX, PDF, PNG ou MP4.
- [x] Possível separar cada slide da apresentação em um ponto que o usuário prefira.
- [x] Possível copiar e colar um mesmo arquivo, sendo assim repetindo ou repetir um slide ou vídeo de um ponto exato.

## Áudio e controle de vídeos
- [x] Controle de volume separado para cada arquivo de vídeo ou som.
- [x] Caso seja vídeo, o usuário consiga apontar onde exatamente termina.
- [x] O vídeo não pode estar mutado.
- [x] Controle de mídia para MP4.

## Projeção, proporção e navegação manual
- [x] Reconhecer a ordem e ser possível pular para determinado arquivo pelo número que foi colocado (apertei 3 foi pro arquivo 3).
- [x] Extremamente importante que o usuário consiga apertar a seta para esquerda ou direita mesmo que em um vídeo ele passe para o próximo arquivo; caso contrário não passe automaticamente, apenas com comando.
- [x] Sempre tudo em tela cheia durante apresentação/projeção.
- [x] Garantir proporções corretas da tela.

## Ajustes de projeção reportados em 08/10
- [ ] Exibir slides sem distorção ou desorganização e manter as transições que já existem no arquivo PPTX.
- [ ] A projeção deve ocupar a tela inteira, sem áreas do editor sobrando.
- [ ] Uma pressão da seta esquerda/direita deve mudar de item, inclusive durante vídeo; segurar a seta não deve buscar segundos no vídeo nem provocar avanço repetido involuntário.
- [ ] Teclar 1 deve ir ao primeiro item desde sua primeira página/início do vídeo, teclar 2 ao segundo item, e assim sucessivamente.
- [ ] Os controles de posição do vídeo devem ficar escondidos sobre o conteúdo e só reaparecer quando o usuário mover o mouse, sem obstruir a exibição.
